# 决策记录

当用户希望比较方案、做出选择或复盘一次决定时使用。

1. 先明确要解决的问题、成功标准和已知约束。缺少决定所必需的信息时，提出简短问题。
2. 列出真正可行的选项，说明每个选项的主要收益、代价和风险。区分已验证事实与推测。
3. 给出建议及理由，并写明什么新信息会改变建议。
4. 按 [记录模板](references/template.md) 输出最终记录。没有证据支持的字段写「待确认」，不要编造。

此 Skill 只提供写作流程，不要求额外系统权限。
